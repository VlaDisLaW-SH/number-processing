# Сервис обработки чисел

Модуль предназначен для нахождения минимального числа из множества чисел, 
которые представлены в локальном файле формата "xmls". Также указывается 
порядковый номер искомого минимального числа.

## Технологии

- Java 17
- Spring Boot 3
- Gradle 8.11

## Требования

- Java 17+
- Gradle 8+

## Установка и запуск локально

### 1. Клонировать репозиторий

```bash
git clone https://github.com/VlaDisLaW-SH/number-processing.git
cd number-processing
```

### 2. Собрать проект
```bash
./gradlew build
```
### 3. Запустить приложение
```bash
./gradlew bootRun
```
